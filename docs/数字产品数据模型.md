## 一、设计背景与核心概念

### 1.1 核心概念澄清

本数据模型严格遵循《数字产品系统架构设计说明书》中的核心抽象：

| 架构文档概念 | 说明 | 旧概念（已废弃） |
| --- | --- | --- |
| **ModuleStructure** | 结构模型，描述产品本体结构 | ProductClass / PartClass |
| **ModuleAttribute** | 属性模型，描述产品业务特征 | BusinessObject |
| **ModuleStructRelation** | 结构间关系（CONTAINS/INSTANTIATES） | offersPart 边 |
| **ModuleStructAttributeRelation** | 结构-属性关系（HAS） | 规格关系 |
| **spec_overrides** | 继承边属性，规格覆盖 | SpecOverride |

### 1.2 Module Structure 层级

```
┌─────────────────────────────────────────────────────────────────────────────────────────────┐
│                          Module Structure（结构模型）层级                                 │
├─────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                             │
│  L1: ProductClass（产品类）                                                                │
│  ├── struct_type = PRODUCT_CLASS                                                          │
│  ├── 示例: ROUTER_PLATFORM（路由器产品平台）                                              │
│  └── 描述: 产品平台的可复用骨架                                                            │
│                                                                                             │

│  ├── 示例: ROUTER_01 / ROUTER_02（路由器销售产品）                                       │
│  ├── 与 ProductClass 关系: INSTANTIATES（实例化）                                        │
│  └── 描述: 确定销售边界的可售产品（对标电商 SKU）                                          │

│                                                                                             │

```

## 二、总体数据模型（核心实体及关系）

### 2.1 核心实体

#### 2.1.1 ModuleStructure（结构模型）

结构模型是描述产品本体结构的实体，包含四种 struct_type：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 全局唯一标识 |
| code | String | 业务编码 |
| name | String | 名称 |
| struct_type | Enum | PRODUCT_CLASS / PRODUCT_INSTANCE / PART_CLASS / PART |
| model_category | String | 固定值 "MODULE_STRUCT" |
| parent_id | UUID | 父节点引用（null 表示根） |
| depth | Integer | 层级深度（L1=0, L2=1, L3=2） |
| status | Enum | DRAFT / PUBLISHED / DEPRECATED |
| version | String | 版本号 |

#### 2.1.2 ModuleAttribute（属性模型）

属性模型是描述产品业务特征的实体，支持六种 attr_type：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 全局唯一标识 |
| code | String | 业务编码（如 SPEC_MAX_BANDWIDTH） |
| name | String | 名称 |
| attr_type | Enum | SPEC / PARAM / MARKETING / DELIVERY / FINANCE / OPERATION |
| model_category | String | 固定值 "MODULE_ATTRIBUTE" |
| schema | JSON | 数据结构定义（type/unit/values） |
| status | Enum | ACTIVE / INACTIVE |
| version | String | 版本号 |

#### 2.1.3 ModuleStructRelation（结构间关系）

描述 ModuleStructure 之间的关系：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 全局唯一标识 |
| code | String | 业务编码（如 PC_Contains_PC） |
| name | String | 名称（如"产品类包含部件分类"） |
| model_category | String | 固定值 "MODULE_STRUCT_RELATION" |
| relation_type | Enum | CONTAINS / EXTENDS / REFERENCES / INSTANTIATES |
| source_id | UUID | 源 ModuleStructure |
| target_id | UUID | 目标 ModuleStructure |
| min_cardinality | Integer | 最小数量 |
| max_cardinality | Integer | 最大数量 |
| default_selected | Boolean | 是否默认选中 |
| selection_policy | Enum | REQUIRED / OPTIONAL |
| edge_attributes | JSON | 边属性（如 enabled_parts、disabled_parts、spec_overrides） |
| version | String | 版本号 |

#### 2.1.4 ModuleStructAttributeRelation（结构-属性关系）

描述 ModuleStructure 与 ModuleAttribute 的关联：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 全局唯一标识 |
| code | String | 业务编码（如 PC_Has_SPEC） |
| name | String | 名称（如"部件分类具备规格属性"） |
| model_category | String | 固定值 "MODULE_STRUCT_ATTRIBUTE_RELATION" |
| relation_type | Enum | HAS / EXTENDS / OVERRIDES |
| dimension | Enum | SPEC / PARAM / MARKETING / DELIVERY / FINANCE / OPERATION |
| structure_id | UUID | ModuleStructure ID |
| attribute_id | UUID | ModuleAttribute ID |
| cardinality_min | Integer | 最小数量 |
| cardinality_max | Integer | 最大数量 |
| inheritance_policy | Enum | OWN / INHERITED / OVERRIDDEN |
| version | String | 版本号 |

### 3.5 UC-A1：创建产品类

**用例描述**：创建一个新的产品类（ProductClass），定义其基本属性。

**参与者**：ACT-01 产品数据架构师

**数据来源**：上游系统（PLM/ERP），不需要本地维护

**关键路径**：
1. 产品数据架构师进入"产品建模"模块
2. 选择"创建产品类"，填写基本信息
3. 系统校验产品类 Code 不重复
4. 系统保存至维护态

**数据模型体现**：


## 附录：术语表

| 术语 | 全称 | 说明 |
| --- | --- | --- |
| **ModuleStructure** | 结构模型 | 描述产品本体结构的实体（ProductClass/PartClass/Part/ProductInstance） |
| **ModuleAttribute** | 属性模型 | 描述产品业务特征的实体（SPEC/PARAM/MARKETING/DELIVERY/FINANCE/OPERATION） |
| **ModuleStructRelation** | 结构间关系 | ModuleStructure 之间的关系（CONTAINS/INSTANTIATES） |
| **ModuleStructAttributeRelation** | 结构-属性关系 | ModuleStructure 与 ModuleAttribute 的关联（HAS） |
| **struct_type** | 结构类型 | PRODUCT_CLASS / PRODUCT_INSTANCE / PART_CLASS / PART |
| **attr_type** | 属性维度 | SPEC / PARAM / MARKETING / DELIVERY / FINANCE / OPERATION |
| **INSTANTIATES** | 实例化关系 | ProductClass → ProductInstance 的继承关系 |
| **spec_overrides** | 规格覆盖 | 继承边上的规格覆盖属性 |
| **edge_attributes** | 边属性 | ModuleStructRelation 上的属性（如 enabled_parts、spec_overrides） |
