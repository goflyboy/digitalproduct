# 数字产品系统 - 低保真原型

基于图的数字产品建模工具，模拟"在画架构图"的设计体验。

## 技术栈

- React 18 + TypeScript
- Ant Design 5.x（UI 组件库）
- React Router 6（路由）
- 内置 SVG 图可视化组件

## 快速启动

```bash
cd prototype-lofi
npm install
npm run dev
```

## 核心设计理念

1. **图即界面**：每个阶段（模板建模/产品模型/实例化）在视觉上都是一张可交互的图
2. **拖拽建模**：像画架构图一样，拖拽节点、连接边
3. **三角色流程**：
   - IT 数据架构师：模板元数据定义
   - 产品数据架构师：产品模型构建
   - 产品数据工程师：实例化与发布

## 页面清单

- `/` - 首页：图概览仪表板
- `/template` - 模板建模（图视角）
- `/model` - 产品模型（图视角）
- `/instance` - 实例化与发布（图视角）
- `/explore` - 图探索模式
