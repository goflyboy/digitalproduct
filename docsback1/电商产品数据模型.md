## 一、电商产品数据模型（核心实体及关系）

### 1.1 核心实体架构图

### 1.2 详细实体关系表

| 实体名称 | 英文名 | 定义 | 关键字段 | 关联关系 |
|---------|--------|------|---------|---------|
| **品类** | Category | 产品分类结构 | category_id, name, parent_id, level, path | 1:N → SPU |
| **品牌** | Brand | 商品品牌归属 | brand_id, name, logo_url, country | 1:N → SPU |
| **SPU** | Standard Product Unit | 标准化产品单元 | spu_id, name, brand_id, category_id, description | N:1 ← Category, Brand; 1:N → SKU |
| **SKU** | Stock Keeping Unit | 库存量单位 | sku_id, spu_id, price, stock, status | N:1 ← SPU; 1:N → OrderItem |
| **属性模板** | Attribute Template | 品类属性定义 | template_id, category_id, attributes[] | 1:N → SPU |
| **属性值** | Attribute Value | SKU具体属性 | attr_id, sku_id, attribute_id, value | N:1 ← SKU, Attribute |
| **销售属性** | Sales Attribute | 销售相关属性(颜色/容量) | sales_attr_id, name, type | 1:N → SalesAttrValue |
| **销售属性值** | Sales Attr Value | SKU销售属性值 | sales_attr_value_id, sku_id, attr_id, value_id | N:1 ← SKU |
| **商品图片** | Product Image | 商品展示图片 | image_id, sku_id, url, sort_order | N:1 ← SKU |
| **商品描述** | Product Desc | 商品详细描述 | desc_id, spu_id, content, images[] | N:1 ← SPU |

## 五、附录

### 5.1 术语表

| 术语 | 全称 | 说明 |
|------|------|------|
| SPU | Standard Product Unit | 标准化产品单元，同一SPU下的商品共享基本属性 |
| SKU | Stock Keeping Unit | 库存量单位，具体到每个可售商品的最小单元 |
| 销售属性 | Sales Attribute | 直接影响用户购买决策的属性，如颜色、容量 |
| 基本属性 | Basic Attribute | 描述商品规格的参数，如屏幕尺寸、电池容量 |

### 5.2 数据流向总结

```
平台运营 → 品类定义 → 属性模板 → SPU创建 → SKU生成
     ↓
商家(店小二) → SKU选取 → 定价 → 库存分配 → 上架销售
     ↓
用户 → 浏览商品 → 加入购物车 → 下单支付
     ↓
系统 → 库存扣减 → 订单履约 → 物流发货 → 交易完成
```
