# 查询图概要信息

> 章节路径：持久化版 / 图统计API / 查询图概要信息
> 来源：https://support.huaweicloud.com/intl/zh-cn/api-ges/ges_03_0465.html

## 查询图概要信息
#### 功能介绍
查询图的点数和边数等概要信息。
#### URI
GET /ges/v1.0/{project_id}/graphs/{graph_name}/summary?label_details={labelDetails}
**表1** 路径参数

| 参数 | 是否必选 | 类型 | 说明 |
---|---|---|---
project_id |  是 |  String |  **参数解释：** 项目编号。获取方法，请参见[获取项目ID](https://support.huaweicloud.com/intl/zh-cn/api-ges/ges_03_0111.html)。 **约束限制：** 不涉及。 **取值范围：** 只能由英文字母和数字组成，且长度为[1-64]个字符。 **默认取值：** 不涉及。
graph_name |  是 |  String |  图名称。
label_details |  否 |  Boolean |  是否返回不同label下点边的数目信息，默认为false。为true时，返回不同label的点边数目。
![](https://support.huaweicloud.com/intl/zh-cn/api-ges/public_sys-resources/note_3.0-zh-cn.png)
  * 若需要返回不同Label下的点数目，新建点索引时索引类型为"GlobalCompositeVertexIndex "且hasLabel为"true"，属性列表置空，新建索引请参考[新建索引](https://support.huaweicloud.com/intl/zh-cn/api-ges/ges_03_0454.html)。
  * 若需要返回不同Label下的边数目，新建边索引时索引类型为"GlobalCompositeEdgeIndex "且hasLabel为"true"，属性列表置空，新建索引请参考[新建索引](https://support.huaweicloud.com/intl/zh-cn/api-ges/ges_03_0454.html)。

#### 响应参数
**表2** 响应Body参数说明

| 参数 | 类型 | 说明 |
---|---|---
errorMessage |  String |  系统提示信息。
  * 执行成功时，字段可能为空。
  * 执行失败时，用于显示错误信息。

errorCode |  String |  系统提示信息。
  * 执行成功时，字段可能为空。
  * 执行失败时，用于显示错误码。

jobId |  String |  执行该异步任务的jobId。 调用查询jobId接口查看任务执行状态、获取返回结果，详情参考[Job管理API](https://support.huaweicloud.com/intl/zh-cn/api-ges/ges_03_0037.html)，调用结果参数说明，详见表3 data参数说明。
**表3** data参数说明

| 参数 | 类型 | 说明 |
---|---|---
vertexNum |  Integer |  图的点数。在多标签场景下，该值会按照label出现次数重复统计，如果需要统计真实实体个数，用cypher语句：match (n) where n is not null return count(*)进行查询。
edgeNum |  Integer |  图的边数。
labelDetails |  Object |  不同label下的点边数目信息。当URL中的label_details参数为true时，会显示此字段。
**表4** 执行成功时，labelDetails数据各要素说明

| 参数 | 类型 | 说明 |
---|---|---
labelInVertex |  Object |  不同label下面点的数目。
labelInEdge |  Object |  不同label下面边的数目。
errorMessage |  String |  系统提示信息。 当没有点索引或边索引时，会显示错误信息，否则字段为空。
errorCode |  String |  系统提示信息。 当没有点索引或边索引时，会显示错误码，否则字段为空。
#### 请求示例
查询图的点数和边数等概要信息，true表示返回不同label的点边数目。
```
    GET http://{SERVER_URL}/ges/v1.0/{project_id}/graphs/{graph_name}/summary?label_details=true
```
![](https://support.huaweicloud.com/intl/zh-cn/api-ges/public_sys-resources/note_3.0-zh-cn.png)
SERVER_URL：图的访问地址，取值请参考[业务面API使用限制](https://support.huaweicloud.com/intl/zh-cn/api-ges/ges_03_0139.html)。
#### 响应示例
**状态码： 200**
成功响应示例
```
    Http Status Code: 200
    {
    "jobId": "f99f60f1-bba6-4cde-bd1a-ff4bdd1fd500000168232"
    }
```
**状态码： 400**
失败响应示例
```
    Http Status Code: 400
    {
        "errorMessage": "Parameter error!",
        "errorCode": "GES.8005"
    }
```
#### 状态码
返回值 |  说明
---|---
400 Bad Request |  请求错误。
401 Unauthorized |  鉴权失败。
403 Forbidden |  没有操作权限。
404 Not Found |  找不到资源。
500 Internal Server Error |  服务内部错误。
503 Service Unavailable |  服务不可用。
